05　把读代码、修改和测试接成一次Agent运行

前几章分别解释了怎样保存消息、怎样发送并记录模型请求，以及历史变长后怎样整理输入。现在把这些动作连起来，继续同一个任务：“修复parser.py，并运行测试确认。”问题变成：谁决定下一步调用模型还是工具？前面那些方法何时才会被执行？

答案是每次运行的一张Deep Agents图。AgentRuntime负责创建和调用这张图，模型与工具路由交给框架；项目把需要执行的历史、权限和结算方法交给它。下面走五步，不把“登记一个以后会调用的方法”写成“这一刻已经执行完所有功能”。

第一步：应用把需要的方法交给Agent，再开始图

会话已经写入运行开始记录（run_start），上一章应用的运行工厂也准备好了模型、工具和当前历史。它调用AgentModule.runtime(model, bindings=...)取得AgentRuntime。这里RuntimeBindings不是另一套服务容器，可以把它读成一张明确的方法清单：消息怎样转成SDK格式、模型怎样计量、工具结果怎样保存、可选功能怎样参加模型前准备。

这些方法不是Agent自己去其他模块找的。应用把Models的转换和请求方法、Tools的结算工厂，以及可能存在的Skill/MCP扩展放进Bindings。以后框架调用到相应位置，Agent才委托它们。这样禁用一个可选功能时，Agent无需在内部判断“这个名称是不是MCP”。

    async def run(self, inputs, context, *, history=()):
        context.initial_inputs = inputs
        context.completed = []
        context.failure_guard = {}
        for message in inputs:
            await context.journal.append_message(message)
            context.completed.append(message)
            if self.title_assignment is not None:
                await self.title_assignment.assign(message)
        self.build(context)
        messages = []
        for message in (*history, *inputs):
            messages.append(self.bindings.to_framework(message, context.selection))
        return await self.invoke(
            {
                "messages": messages,
                "session_id": context.session_id,
                "run_id": context.run_id,
                "turn": 0,
                "outcome": "running",
                "final_text": "",
                "failure_count": 0,
            },
            context,
        )

    def build(self, context):
        # Explicit registration at construction, never at import. The public
        # harness profile disables summarization in both parent and subagents.
        provider = context.selection.implementation
        if not provider:
            raise ModelError("provider_identity_missing", "Model must report its provider identity")
        register_harness_profile(
            provider,
            HarnessProfile(
                excluded_middleware=frozenset({"SummarizationMiddleware"}),
                general_purpose_subagent=GeneralPurposeSubagentProfile(enabled=False),
            ),
        )
        tools = []
        for spec in context.registry.model_specs():
            tools.append(self.bindings.make_framework_tool(spec, context))
        file_tools: list[FsToolName] = ["ls", "read_file", "glob", "grep"]
        if not self.read_only:
            file_tools.extend(["write_file", "edit_file"])
        filesystem = FilesystemMiddleware(
            backend=self.backend,
            tools=file_tools,
            tool_token_limit_before_evict=None,
            human_message_token_limit_before_evict=None,
            custom_tool_descriptions={
                "grep": (
                    "Search workspace text using ripgrep regular expressions. Honors ignore files; "
                    "returns bounded matches with explicit incomplete/error status."
                )
            },
        )
        middleware = [
            filesystem,
            TodoListMiddleware(),
        ]
        if self.instructions and self.instruction_backend is not None:
            # Loaded once per run into private graph state and appended to the system message
            # of every model call; never written to JSONL history, so compaction cannot drop it.
            middleware.append(
                MemoryMiddleware(
                    backend=self.instruction_backend,
                    sources=list(self.instructions),
                    system_prompt=AGENTS_MD_PROMPT,
                )
            )
        for extension in self.bindings.framework_extensions:
            middleware.append(
                extension.middleware(
                    context,
                    self.backend,
                    lambda request: prepare_model_boundary(request, self.bindings),
                    self.bindings.make_framework_tool,
                )
            )
        middleware.extend(
            [HistoryMiddleware(self.bindings), self.bindings.settlement_middleware_factory(context)]
        )
        self.graph = create_deep_agent(
            model=self.model,
            tools=tools,
            backend=self.backend,
            subagents=list(self.subagents),
            middleware=middleware,
            state_schema=PycodeState,
            context_schema=RunContext,
            checkpointer=self.checkpointer,
            name="pycode",

    async def invoke(self, value, context):
        graph = self.graph
        if graph is None:
            raise StorageError("run_expired", "This runtime has no live execution graph")
        try:
            state = await graph.ainvoke(value, config=self.config(context), context=context)
        except asyncio.CancelledError:
            await self.collect_tools(context)
            if context.summary is not None:
                await context.summary.cancel_background()
            await context.events.emit("agent_end", {"outcome": "aborted"})
            raise
        except (ModelError, GraphRecursionError) as error:
            code = error.code if isinstance(error, ModelError) else "framework_execution_limit"
            await context.events.emit("error", {"code": code, "message": str(error)})
            await context.events.emit("agent_end", {"outcome": "error"})
            return RunResult("error", "", tuple(context.completed))
        except BaseException:
            await self.collect_tools(context)
            if context.summary is not None:
                await context.summary.cancel_background()
            raise
        pending = []
        checkpoint = await graph.aget_state(self.config(context))
        checkpoint_id = checkpoint.config.get("configurable", {}).get("checkpoint_id")
        if not isinstance(checkpoint_id, str):
            raise StorageError("checkpoint_missing", "Live execution checkpoint has no identity")
        for item in state.get("__interrupt__", ()):
            question = {"interrupt_id": item.id, "checkpoint_id": checkpoint_id, **item.value}
            pending.append(question)
            await context.events.emit("needs_input", question)
        if pending:
            return RunResult(
                "needs_input", "", tuple(context.completed), tuple(pending), checkpoint_id
            )
        return RunResult(
            state.get("outcome", "completed"),
            state.get("final_text", ""),
            tuple(context.completed),
            checkpoint_id=checkpoint_id,
        )

第二步：每次问模型前，先整理旧内容，再交付新补充

框架进入HistoryMiddleware.abefore_model时，当前图已经存在，但这次还没有发送模型请求。该方法使用当前选定模型，把三个本地闭包接成 LangChain 顺序步骤：整理已有消息、保存用户补充的即时要求、重新生成这次要发送的消息。

第一段先调用应用注入的准备方法，例如把最新MCP声明放入registry，再调用上一章的summary.prepare。随后把摘要正在使用的消息ID交给eviction，避免旧测试输出省略动作破坏正在生成的摘要。不是History自己解析MCP或重写摘要算法，而是把当前状态交给已经接好的方法。

    async def abefore_model(self, state, runtime):
        context = runtime.context

        async def maintain_context(current):
            for callback in self.bindings.before_model:
                await callback()
            summary = None
            if current.summary is not None:
                current.summary.set_tools(current.model_tools or current.registry.model_specs())
                summary = await current.summary.prepare()
                if summary.applied_job_id is not None:
                    await self.bindings.run_hook(current, "compact", summary.applied_job_id)
            if current.eviction is not None:
                await current.eviction.apply(
                    protected_entry_ids=summary.protected_entry_ids if summary else ()
                )
            return current

        async def deliver_steering(current):
            if current.team is not None:
                await current.team.flush_inbox(current)
            if current.durable_inputs is not None:
                current.inputs = await current.durable_inputs.pending(current.run_id)
            pending = current.inputs.take("steer", one_at_a_time=current.one_at_a_time)
            for message in pending:
                await deliver_input(current, message, "steer")
            return pending

        async def project_turn(pending):
            turn = state.get("turn", 0) + 1
            await self.bindings.run_hook(context, "turn_start", f"{context.run_id}:turn-{turn}")
            if turn > 1:
                await context.events.emit("turn_start", {"turn": turn})
            updates: dict[str, Any] = {"turn": turn}
            if context.history_store is not None:
                projection = await self.current_projection(context)
                messages: list[BaseMessage] = [RemoveMessage(id=REMOVE_ALL_MESSAGES)]
                for message in projection.messages:
                    messages.append(self.bindings.to_framework(message, context.selection))
                updates.update(messages=messages, branch_leaf_id=projection.leaf_id)
            elif pending:
                updates["messages"] = [
                    self.bindings.to_framework(message, context.selection) for message in pending
                ]
            return updates

        await maintain_context(context)
        pending = await deliver_steering(context)
        return await project_turn(pending)

    async def resume(self, context, answers=None):
        if self.graph is None:
            raise StorageError(
                "run_expired", "This process has no active run; open history and start a new task"
            )
        checkpoint = await self.graph.aget_state(self.config(context))
        if not checkpoint.interrupts:
            raise StorageError("no_pending_run", "No live question is awaiting an answer")
        value = None
        if answers is not None:
            if not isinstance(answers, dict):
                raise StorageError("invalid_resume", "Answers must be an object")
            interrupts = checkpoint.interrupts
            identifiers = {item.id for item in interrupts}
            if set(answers).issubset(identifiers) and answers:
                for item in interrupts:
                    if item.id in answers:
                        validate_operation_answer(
                            item.value,
                            answers[item.id],
                        )
                value = Command(resume=answers)
            elif len(interrupts) == 1:
                validate_operation_answer(
                    interrupts[0].value,
                    answers,
                )
                value = Command(resume={interrupts[0].id: answers})
            else:
                raise StorageError("invalid_resume", "Multiple questions require interrupt IDs")
        context.dispatched_calls.difference_update(context.interrupted_calls)
        context.interrupted_calls.clear()
        return await self.invoke(value, context)

走完五步，再回查组装和框架职责

这次任务始终只有当前run的一张Deep Agents图。AgentModule提供runtime、Bindings、publisher和默认InMemorySaver；应用提供已经选好的模型、后端、工具方法和可选扩展。Launcher保留等待中的runtime，运行不再需要时由它和RuntimeContainer负责关闭；Agent不会自己创建一套模型客户端。

框架负责在模型和工具节点间转交执行、按约定调用中间件、保存图的运行位置，以及暂停等待用户回答。项目在相应回调中补的是：问模型前怎样整理输入，完整assistant何时落盘，实际工具是否获准，多个结果怎样保存，以及取消时要等待哪些已开始的任务。因此，读到下面这些名字时，应该能把它们放回刚才经过的步骤，而不是把它们当成互不相关的功能清单。

读懂检查：能否自己顺着修复过程讲一遍

  • 完整assistant为什么必须在工具执行前保存？ 后续调用要证明它属于这条模型指令，部分流式文字不能提供这个保证。
  • 为什么不能构图时就说所有工具已经给模型看过？ MCP会在模型前刷新，Skill资源由resolver按需加入，最终名单要在它们完成后确认。
  • 模型前去掉写工具，是否已经安全？ 还不够。真实调用仍要检查当前参数、说明版本、权限和沙箱条件。
  • 两个工具反序返回，谁决定JSONL顺序？ Settlement按原assistant的call_order保存，不按网络返回快慢排序。
  • 用户回答后为什么不重新打开一个Agent？ 正确恢复需要仍存在的图、它保存的运行位置，以及正在等待的问题；新图不能继承旧批准。
  • aafter_agent再跳回model，是否是第二套执行循环？ 不是，它返回框架支持的jump_to，让同一张图继续。
  • 为什么不能说run结束就是会话关闭？ TUI会话可以继续接受下一任务；后台摘要、Hook和连接的关闭由对应持有者处理。

至此，“用户提出修复→模型决定读代码→工具经过审批执行→测试结果保存→模型继续或结束”已经接通。接下来的工具章会放大第四步，进一步看工具参数说明、读取过的文件版本、权限和完整输出怎样真正阻止错误修改，而不是只在提示词中提醒模型小心。

Team 的进程内交接

子任务无活动超时后，Team 先停止旧执行并确认工具收尾，再把同一任务的执行线程、内存 checkpoint、历史和 worktree 交给新成员。continue_task 继续原图；普通取消与程序重启不会假装保留这种续接能力。活动来自模型和工具事件，不依赖成员自报存活。详细状态和验收流程见 Team 章节。
