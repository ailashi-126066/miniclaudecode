# 11　同步 Hook：提醒、检查和拦截

Hook 在已有 Agent 或工具执行边界触发，不创建另一个 Agent，也不安排后台任务。配置仅支持同步 command 和 prompt，用于提醒、检查以及明确拦截。

## 配置和组装

## 后置提醒与中断

工具结果保存后再触发后置 Hook。普通后置失败记录为失败并交给 Agent，不重新执行原工具，也不自动回滚。prompt 只追加上下文，不额外请求模型。

若重开后发现某个 Hook 已开始却没有结果，保留 hook_interrupted 记录，不自动重跑。没有专门的中断核对界面、确认结果、重试或放弃命令。新的事件仍按当前配置触发新的同步检查。

command 仍通过现有进程 runner 和沙箱执行；“用于检查”是配置用途，不表示任意 shell 命令在技术上天然不能修改文件。只读模式、Plan 和沙箱限制继续生效。

## 框架负责什么

Deep Agents / LangGraph 驱动 Agent 循环，HistoryMiddleware 与工具执行器在已有边界调用 Hook。项目负责匹配规则、执行同步动作和记录事实，不实现额外调度循环。
