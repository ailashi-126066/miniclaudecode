# 09　本地 Skill 的读取、创建与安装

Skill 是本地说明文件及附属脚本，不是额外的 Python 工具插件。Agent 通过框架读文件工具读取 SKILL.md，需要执行脚本时使用已有 Bash。

## 准备目录与加载

会话组装入口打开 SkillsSession，运行入口准备 SkillsRun。运行时只消费准备好的工具、只读目录挂载和权限约束，不在缺少输入时重新建立 Skill 会话。独立加载和会话加载共用目录挂载实现。



Deep Agents SkillsMiddleware 负责加载和注入说明，项目补充可信目录、预算、按需选择与读取记录。本地工具和 MCP 工具统一由 ToolSearch 提供简表并加载定义；SkillSearch 查询的是 Skill 文档目录，两者搜索对象不同。

## 使用、创建与更新

Skills.load 准备用户消息，由 AgentSession 负责发起一次运行。Skills.read 返回正文；create/update 原子写入本地定义，更新使用 expected_revision 避免覆盖其他修改。SaveSkill 通过正常工具审批执行。

## 安装与执行脚本

安装器下载 Skill 到本地，校验目录与内容后保存。安装不自动执行其中脚本。需要脚本时，由 Agent 使用普通 Bash，继续经过现有沙箱、只读与审批边界。
